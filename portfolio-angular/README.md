# Projeto Angular

## Descrição

Este projeto foi desenvolvido utilizando o framework Angular com o objetivo de criar uma aplicação web moderna, responsiva e organizada em componentes. A aplicação utiliza os recursos do Angular para gerenciamento de rotas, componentes, serviços e comunicação com APIs.

## Tecnologias Utilizadas

* Angular
* TypeScript
* HTML5
* CSS3
* Node.js
* npm

## Ambiente de Desenvolvimento

Para garantir a reprodução do ambiente utilizado no desenvolvimento, seguem as versões instaladas:

| Ferramenta  | Versão  |
| ----------- | ------- |
| Node.js     | vXX.X.X |
| npm         | X.X.X   |
| Angular CLI | X.X.X   |

> Substitua os valores acima pelas versões instaladas em sua máquina.

## Instalação

Clone o repositório:

```bash
git clone <url-do-repositorio>
```

Acesse a pasta do projeto:

```bash
cd nome-do-projeto
```

Instale as dependências:

```bash
npm install
```

## Execução

Para iniciar o servidor de desenvolvimento:

```bash
ng serve
```

A aplicação estará disponível em:

```text
http://localhost:4200
```

## Estrutura do Projeto

* `src/app/components` — Componentes da aplicação
* `src/app/services` — Serviços e comunicação com APIs
* `src/assets` — Arquivos estáticos
* `src/environments` — Configurações de ambiente
